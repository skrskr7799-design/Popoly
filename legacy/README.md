# Legacy prototype archive

This directory preserves the complete pre-foundation Popoly prototype as it existed on the target `main` branch immediately before the Tech Dominion foundation cutover.

- Source repository: `skrskr7799-design/Popoly`
- Source branch: `main`
- Exact source commit: `3c8c1183490562111f820dafd602eca18826df11`
- Snapshot location: `legacy/prototype/`
- Archive contents: all tracked files from the source commit, including the original `src/`, root build configuration, Docker files, and Docker publish workflow.

The snapshot is retained for reference and recovery. It is not part of the active Vite build. The live application remains in the repository root and is launched through `src/main.tsx`.

To inspect the original prototype, review `legacy/prototype/README.md` and its original source tree. Do not edit this archive as part of routine game development; make any future restoration or extraction explicit and traceable.
